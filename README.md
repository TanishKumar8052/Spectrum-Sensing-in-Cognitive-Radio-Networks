# Spectrum-Sensing-in-Cognitive-Radio-Networks

Spectrum sensing is the process of detecting unused portions of the licensed spectrum (spectrum holes/white spaces) so that unlicensed (secondary) users can opportunistically access them without interfering with licensed (primary) users. This is a key function in cognitive radio networks, enabling efficient spectrum utilization.

# Spectrum Sensing using Multi-Coset Sampling

Conventional sensing requires Nyquist-rate sampling of wideband signals, which is hardware-expensive. Multi-Coset Sampling reduces the rate by:

Dividing the wideband signal into multiple cosets (time-shifted sub-samples).

Sampling each coset at a lower rate.
